# 📊 Maven Market Retail Analytics Dashboard

An interactive **Power BI dashboard** built using Maven Market retail data to analyze **sales, profit, returns, brand performance, and revenue targets** across the USA, Canada, and Mexico.

## 🔍 Key Analysis

* Sales and profit performance
* Return rate and return distribution
* Brand-level performance
* Revenue vs target analysis
* Country → Region → District → Store → Product drill-down
* Store-level return analysis

## 🛠️ Tools & Technologies

**Power BI | DAX | Data Modeling | Data Visualization**

## 📌 Dashboard Features

* KPI Cards
* Interactive Slicers
* Drill-Through Analysis
* Decomposition Tree
* Treemap
* Map Visualization
* Revenue vs Profit Trend
* Revenue vs Target Gauge
* Brand Performance Table

**Dataset:** Maven Analytics
